# MongoDB Java Driver

Official Java sync driver 5.11.1 from Maven Central:

- https://repo.maven.apache.org/maven2/org/mongodb/mongodb-driver-sync/5.11.1/mongodb-driver-sync-5.11.1.jar
- https://repo.maven.apache.org/maven2/org/mongodb/mongodb-driver-core/5.11.1/mongodb-driver-core-5.11.1.jar
- https://repo.maven.apache.org/maven2/org/mongodb/bson/5.11.1/bson-5.11.1.jar

Keep these three jars in this directory. The driver is Apache License 2.0;
licenses and notices are included in the jars.
